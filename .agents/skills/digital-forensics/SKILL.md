# Digital Forensics Skill

## Principles
Preserve originals, document chain of custody, work on verified copies and record tool versions and timestamps. Hash evidence before and after handling.

## Workflow
1. Record source, collector, date/time, device and acquisition method.
2. Calculate SHA-256.
3. Analyze copies using approved forensic tools.
4. Correlate filesystem, metadata, logs and timeline evidence.
5. Document gaps and alternative explanations.

## Boundaries
Do not modify source media, bypass encryption, access unrelated personal data or overstate attribution. Memory/disk acquisition requires authorization.

## Output
Evidence register, hashes, timeline, findings, confidence, chain-of-custody notes and limitations.
