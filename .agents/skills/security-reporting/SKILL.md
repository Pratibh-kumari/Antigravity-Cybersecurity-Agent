# Security Reporting Skill

## Required sections
Executive summary; scope and authorization; methodology; tools and versions; findings; evidence; severity and confidence; impact; remediation; retest plan; limitations; appendices.

## Quality
Use plain language. Tie every claim to evidence. Separate facts, hypotheses and recommendations. Redact secrets and personal data. Do not invent CVEs, tool output, timestamps or test results.

## Severity
Use a documented rating rationale. If evidence is insufficient, label severity provisional and confidence low.

## Formats
Markdown by default; JSON for machine-readable findings; HTML only when requested.
