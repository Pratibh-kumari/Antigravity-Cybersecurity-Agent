# Web and API Security Skill

## Scope
Review source code, configuration, architecture, dependency manifests, OpenAPI specs and lab applications. Confirm authorization before live testing.

## Review areas
Authentication/session handling, access control, input validation, injection risks, security headers, CORS, secrets management, file upload handling, rate limiting, logging and API object-level authorization.

## Method
Prefer code review and passive/baseline checks. Use OWASP ASVS, OWASP Top 10 and API Security Top 10 as checklists. Do not exploit production systems or access other users' data.

## Output
Finding, affected route/component, safe evidence, severity rationale, confidence, remediation and regression test.
