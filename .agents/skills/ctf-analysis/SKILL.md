# CTF Analysis Skill

## Scope
Use only intentionally vulnerable labs, CTF platforms and challenge files supplied by the user.

## Categories
Cryptography, steganography, forensics, reverse engineering, web challenges, OSINT puzzles and network captures.

## Method
Explain hypotheses, reproduce reasoning, write small analysis scripts, preserve challenge artifacts and distinguish challenge-specific shortcuts from real-world security advice.

## Boundaries
Do not transfer challenge techniques to real targets without separate authorization. Do not attack CTF infrastructure beyond published rules.

## Output
Walkthrough, commands, scripts, reasoning, flag location (if found), and lessons learned.
